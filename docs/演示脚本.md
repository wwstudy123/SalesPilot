# SalesPilot MVP 演示脚本

## 冷启动

```powershell
docker compose -f compose.full.yml up --build -d
docker compose -f compose.full.yml --profile seed up --build business-seed seed
```

等待 `mysql`、`redis`、`milvus` 与 `business-mock` 健康后，打开 `http://localhost:8088`。

## 故障预案

| 场景 | 预期降级 | 操作 |
|---|---|---|
| LLM 超时/未配置 Key | Gateway echo/通用建议，不阻断建议卡 | 检查 `SALE_LLM_*`，演示可继续 |
| SSE 断开 | 前端重新发送同一诉求；Run 仍可在 Monitor 查询 | 刷新聊天页后重试 |
| 提案过期 | 30 分钟后状态为 `expired`，重新分析生成新提案 | 点击重新分析/重新打标 |
| 无凭证写入 | MCP 返回 `E_APPROVAL_REQUIRED` | 仅通过建议卡确认写入 |
| Milvus 不可用 | `SALE_VECTOR_BACKEND` 自动回落 lite | 检查 `/api/ai/health` 后继续演示 |
