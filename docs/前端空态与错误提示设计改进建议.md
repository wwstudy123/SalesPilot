# 前端空态与错误提示设计改进建议

> 来源：排查「灌入种子」提示反复出现时发现的页面体验问题。

## 背景

工作台（`HomePage`）、我的客户（`CustomersPage`）、知识库（`KbSearchPage`）在数据加载无常时会提示「`make seed` 灌入种子并重新登录」。该文案存在 **开发术语暴露**、**错误态与空态同时触发**、**初始化入口放错位置** 等问题。

## 问题清单

### 问题 1：错误态与空态同时显示（体验 Bug）

`CustomersPage.tsx`（L55-59）：

| 状态 | 判断 | 文案 |
|------|------|------|
| 加载中 | `isLoading` | 加载中… |
| 出错了 | `isError` | 加载失败：No static resource ... |
| 空数据 | `!isLoading && length === 0` | 暂无客户，请先 make seed |

**缺陷**：接口报错时 `customers` 为空数组，`length === 0` 的**空态分支也会同时触发**，导致「既报错又提示灌种子」的混乱文案。实际上数据在库里，只是接口 404。

**影响**：之前排查的 `No static resource /api/v1/customers/3/tags` 404 时，页面同时显示了错误和空态两行，误导排查方向。

### 问题 2：开发命令术语暴露给终端用户

- `make seed` 是**开发初始化命令**，普通销售员工无法也不应执行
- 「重新登录」暗示用户端操作，但实际是开发环境才需要的
- 页面面向**业务用户**（销售员工/店长），不应出现命令行术语

### 问题 3：种子按钮放错位置

`KbSearchPage.tsx`（L103）在面向用户的知识库页暴露「灌入种子」按钮。灌种是**开发/初始化动作**，应收进管理端或开发者入口。

## 改进建议

| 项 | 现在 | 建议 |
|----|------|------|
| 错误态 | 与空态同时触发 | **互斥**：`isError` 时只显示「加载失败，请稍后重试」，不引导灌种 |
| 空态 | 由 `length===0` 触发且带 make seed 文案 | 空态只由**后端 200 空数组**触发才算真空；文案面向用户：「暂无客户数据」 |
| 灌种按钮 | 公开在知识库页 | 移到**管理端**（仅 manager 可见）或删除 |

## 实施要点（涉及 3 个页面，改后前端热更新即时生效）

1. **CustomersPage.tsx**
   - 空态分支改为 `!isLoading && !isError && customers.length === 0`
   - 文案改为面向用户：「暂无客户数据」
2. **HomePage.tsx**
   - 与上同：`isError` 优先且独占地显示错误；空态不带命令术语
3. **KbSearchPage.tsx**
   - 移除公开的「灌入种子」按钮，或移到管理端权限内

## 额外说明

- seed（种子）本身是**预置演示数据**的初始化工具（`seed.sql` → CRM 业务数据；`python -m sale_agent.kb.seed` → 知识库数据），用于开发/演示期开箱即用，不是业务功能入口。
- 空态引导「如何初始化」属于**开发环境**需求，更适合放在 README / 演示脚本，而非面向用户的页面。
